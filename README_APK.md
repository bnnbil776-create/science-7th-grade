# مشروع تطبيق كتب اليمن التعليمية 3D (ملف تثبيت أندرويد APK)

هذا المشروع جاهز لتوليد ملف تثبيت أندرويد (`app-debug.apk`) مجاناً عبر **GitHub Actions** أو **Android Studio** بدون الحاجة لدفع أي رسوم.

## طريقة استخراج ملف الـ APK مجاناً عبر GitHub (الأسرع):
1. أنشئ مستودعاً (Repository) جديداً ومجانياً على GitHub.
2. ارفع جميع ملفات هذا المشروع إلى المستودع.
3. سيبدأ تلقائياً مسار العمل الموجود في `.github/workflows/build-apk.yml` ببناء التطبيق.
4. بعد انتهاء البناء (حوالي 2–3 دقائق)، ادخل إلى تبويب **Actions** ثم اختر آخر عملية ناجحة وحمّل الملف المرفق **`yemen-3d-textbooks-apk`** الذي يحتوي على `app-debug.apk`.
5. انقل ملف `app-debug.apk` إلى جوالك وثبّته مباشرة (مع تفعيل "التثبيت من مصادر غير معروفة" عند الحاجة).

## إضافة باقي الكتب والمناهج لاحقاً:
- يمكنك إضافة دروس أو كتب جديدة داخل الملف `app/src/main/assets/index.html` ثم رفع التحديث إلى GitHub ليتم توليد نسخة APK جديدة تلقائياً.
